# JLU-知识产权法律基础

中国知识产权远程教育平台“知识产权法律基础（大学版）”的视频顺序播放辅助脚本。

正常播放当前视频，播完后自动选择目录中的下一条视频；遇到目录中独立的练习页时，尝试进入后续视频。脚本不提交练习、不修改倍速或学习记录。

当前版本：**v0.7.0**。

## 安装与使用

1. 在 Edge 或 Chrome 中安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. 确认扩展已启用，并在浏览器扩展设置中开启“允许用户脚本”。没有该开关的版本，参考[油猴官方说明](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)。
3. 点击[安装 / 下载脚本](https://raw.githubusercontent.com/kbpg/ciptc-course-helper/main/ciptc-video-helper.user.js)；如果浏览器弹出油猴安装页，确认安装。也可以下载 `.user.js` 文件，在油猴管理面板的“实用工具 → 导入文件”中导入。
4. 从学习平台正常进入这门课程，再刷新课程标签页。
5. 看到 **“CIPTC 自动顺序播放 · v0.7.0”** 后，脚本会自动识别当前章节并开始处理，无需点击绿色目录。
6. 如果浏览器阻止自动播放，手动点一次播放器的播放按钮。

更新时覆盖旧版，仅保留一个版本启用。不要直接打开资源页的裸地址；从学习平台进入可保留正常的课程参数。

## 自动播放规则

- 当前视频正常播放结束后等待 5 秒，再点击目录中的下一段视频。
- 当前在独立练习目录项时，等待 2 秒后尝试选择后续视频。
- 运行时自动关闭网站原有的“自动播放列表”，由脚本统一切换。
- 一次只请求切换一段视频；15 秒未确认切换则暂停并提示。
- 目录中没有后续视频时自动停止。

例如：第 21 段 → 第 22 段 → 第 23 段 → 第 24 段。

## 面板操作

| 按钮 | 作用 |
| --- | --- |
| 暂停 / 恢复自动连播 | 控制后续自动切换 |
| 重新识别并启动 | 处理完页面提示后恢复运行 |
| 导出目录诊断 | 下载诊断 JSON，辅助排查目录或框架识别问题 |

诊断文件保存在本地，不会自动上传。
